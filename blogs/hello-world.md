## 为什么自己搭

用现成的写作平台显然更省事，但我还是想自己搭一个，理由大概有三条：

1. **数据完全属于自己。** 文章就是仓库里的一组 Markdown 文件，没有平台会突然关停，也没有编辑器会绑架你的格式。
2. **想怎么折腾就怎么折腾。** 想加个主题切换、想改个排版，改代码就行，不用等平台更新。
3. **顺手练手。** 搭站本身就是一个挺好的前端练习。

代价当然也有——没有评论区，没有推荐流量，写完大概率只有自己看。不过对一个用来整理思路的地方来说，这算不上问题。

## 技术栈

这个站点的构成非常简单：

- [React 19](https://react.dev/) + [Vite](https://vite.dev/) + TypeScript
- 文章写在这个仓库的 `blogs/` 目录里，一个 `.md` 一个文件
- 构建产物是纯静态文件，push 之后由 GitHub Actions 自动发布到 GitHub Pages

没有后端，没有数据库，也没有评论系统。整套东西就是一堆静态文件。

## 接下来写什么

大概会是这几类：

- 踩坑记录，尤其是那些「查了半天文档最后发现是一行配置写错」的
- 工具和配置的心得
- 偶尔一些纯粹的想法

> 写下来的过程本身就是一次整理。很多问题在敲字的时候才会暴露出来。

那么，就这样开始了。
