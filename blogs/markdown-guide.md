这篇文章既是排版速查，也是这个站点的功能自测。写它是因为：**公式这块有个不直观的坑**，值得单独记一笔。

## 标题与文本

用 `##` 到 `######` 写标题就行。**二级标题会自动出现在文章开头的目录里**，三级标题缩进一级显示。

普通的强调用 `**加粗**`、`*斜体*`、`~~删除线~~`，行内代码用反引号包起来，比如 `npm run dev`。

链接写成 `[文字](https://example.com)`，例如 [Vite 官网](https://vite.dev/)。

## 列表与引用

有序和无序列表都支持，也可以嵌套：

1. 第一步
2. 第二步
   - 子项 A
   - 子项 B
3. 第三步

> 引用块长这样。适合放结论、注意事项或者别人的话。

## 代码

行内用反引号，成块的用三个反引号加语言名：

```ts
const posts = Object.entries(files).map(([path, raw]) => {
  const { data, content } = parseFrontMatter(raw)
  return { slug: path.split('/').pop()!.replace(/\.md$/, ''), ...data, content }
})
```

```bash
npm run dev      # 本地开发
npm run build    # 构建到 dist/
```

| `$x^2$` | 行内公式 |

## 数学公式

公式用 [KaTeX](https://katex.org/) 渲染，语法就是标准 LaTeX。

### 行内公式

用单个 `$` 包起来，会跟正文排在同一行：质能方程 $E = mc^2$ 大概是最有名的公式了。中文里直接贴着文字写也没问题，比如这个求和 $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$ 就嵌在句子里。

### 块级公式

用 `$$` 包起来、**并且单独占行**，就会居中独立显示：

$$
\int_{-\infty}^{+\infty} e^{-x^{2}}\,\mathrm{d}x = \sqrt{\pi}
$$

带希腊字母、上下标和分数的复杂一点的也没问题：

$$
\frac{\partial u}{\partial t} = \alpha \nabla^{2} u + f(\mathbf{x}, t)
$$

矩阵：

$$
\mathbf{A} = \begin{pmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{pmatrix}
$$

### 坑：美元符号要转义

为了照顾中文排版（中文字和公式之间通常不打空格），这个站点开启了非标准的宽松匹配：**`$` 前后不加空格也能识别公式**，所以「质能方程是 $E=mc^2$」这样贴着中文写没问题。

代价是：正文里要显示真正的美元符号，必须写成 `\$`。

| 源码里写 | 页面上显示 |
| --- | --- |
| `\$100` | \$100 |
| `$100` | 两个 `$` 之间的内容会被当成公式 |

一句话：**想让 `$` 原样显示，就在前面加个反斜杠。**

（反引号包起来的代码片段里不受影响，`$` 不会被当成公式。）

## 图片

图片语法和链接一样，只是前面多个感叹号，路径指向 `public/` 里的文件（比如 `![头像](/avatar.jpg)`）。

---

## 小结

排版能力一览：

- 标题、列表、引用、表格、代码块、图片 —— 都支持
- 行内公式 `$...$`、块级公式 `$$...$$` —— 由 KaTeX 渲染
- 目录按 h2/h3 自动生成，滚动时会高亮当前小节
